# OWNER_LOCALIZATION_DECISION_20261113

Status: OWNER_APPROVED_ACTIVE
Date: 2026-11-13
Owner: HKIA Editor project owner
Decision: Support every language officially supported by Hello Kitty Island Adventure; use browser language by default, user-changeable, and exact game-provided localized names and text. This is a binding formal-release requirement and extends the 2026-11-13 architecture execution decision; it does not authorize a deployment, Writer flag change, or raw asset publication.

## Scope and authority
- Enumerate languages from actual HKIA localization tables, language-selector/config metadata and version/platform evidence (Switch 3.0.0 / 3.0.1). Corroborate official platform metadata; do not assume DDV/Wand locale count, Steam parity, regional alias equivalence or all strings exist. Record canonical BCP47 code, game locale ID, display native name, direction, fallback chain, version/source SHA and coverage. Exact language inventory is not yet verified.
- Extract exact game title/name, description, item, recipe, collection, category, achievement, reward label and other game-derived display text required by current editor; future domains reuse same interface. Join stable game IDs/GUIDs/Localization Keys, not translated names; preserve Unicode, punctuation, placeholders, plural/markup semantics and version distinctions. Use existing data/local-achievement-locales.json (820 v301 records, EN/JA title 820 each, descriptions 720 each) and existing crosswalks, no re-extraction of exact proven values. Do not translate missing game text by AI or infer labels; distinguish actual absent description, missing extraction, unknown ID, and verified game fallback. Track every key/locale/version, reject collisions, show explicit fallback or unknown labels, never mislabel fabricated text as game localization.
- Editor-owned UI strings: complete catalogs for all supported game locales, including tabs, menus, search, filters, editing, progress/date/time, warnings, errors, capability reasons, dialogs, tooltips, accessibility, credit and privacy notices. Validate key completeness, placeholder/plural parity, safe interpolation and language quality. Do not use game text as translation authority for editor-specific strings.
- Default: ordered navigator.languages then navigator.language; canonical exact match then explicit verified script/region aliases, fallback English if supported else verified game default. Do not collapse distinct Chinese scripts or regional variants. Manual selector uses native names, explicit Auto/browser option, persists only locale preference in HKIA-local storage; manual overrides auto until reset; storage unavailable/corrupt handled safely. Set document lang/dir and use Intl date/number/collation/search, without changing saved timestamps or IDs. Changes must not mutate Save, invalidate plans/undo, reset session, lose selection or trigger external requests. Lazy-load versioned locale packs, deterministic fallback, no whole-save transfer. Rust/WASM ABI keeps stable IDs; presentation is Svelte+TS.
- Formal release gate: full proven language inventory, source provenance/coverage of required present keys, complete editor catalogs, independent per-locale runtime and layout/accessibility verification, artifact manifest and privacy/credits. Missing actual game strings explicitly classified; no silent partial language claim. JS functional Beta remains independent, V24 frozen; add verified locales when ready without introducing new Beta gate or unauthorized deploy.
- Game localization use requested by Owner; derived minimum text only, existing rights attribution (Sunblink/SANRIO and relevant rights holders), unofficial/non-affiliated, no claim of license or endorsement. Exclude raw localization bundles, original binaries, private IDs, Save data and research fixtures from Git/CI/public artifact; private source evidence stored only in existing authorized workspace. Rights/privacy approval boundaries unchanged.
