New wasm-bridge cdylib wraps the sole ProductSession::new_private_writer, never production flags. No new JS Writer, no save storage/network.

HKE1 request: same 78-byte LE stamp layout as HKS1, magic HKE1. Ops 1 Plan (u16 count 1..128; edit tag1 i32 item,i64 old,i64 next; tag2 u32 achievement,counter,old_bits,next_bits), 2 Preview and 3 Apply (u64 plan ID), 4 Verify, 5 Export, 6 Backup, 7 Undo, 8 Redo, 9 Reset (empty). No extra bytes. Both protocols share Rust high-water ID/Generation/Revision/Runtime/Source CAS. HKE1 responses use the HKS1 77-byte identity prefix, ok flag, then error pair or typed tag: 1 PlanInfo, 2 PlanInfo+Proof, 3 Applied Proof, 4 Verified Proof, 5 Export digest/u32 bytes, 6 Backup digest/u32 bytes, 7 Restored digest/bool edited. PlanInfo: u64 id,u8 version,32-byte base,32-byte schema,u16 diff count, ordered typed fields (tag/i32 item or u32 doc+4 u32 GUID, u32 start/end, typed old/next scalars tag1 i64 or tag2 u32 f32 bits,32-byte raw digest). Proof: digest, u32 bytes/fields/reused/reencoded/non-target. Metadata capped 32KiB; no output except Export/Backup separate transferred buffer. No partial output on failure. HKS1 remains read-only and does not advertise Writer.

Bridge exports bounded stage, init, invoke, reply/output ptr+len, release; no unsafe blocks, pointers are wasm32 addresses of live owned allocations, JS writes only stage. Reacquire memory view after allocation/growth, copy results before release. Runtime nonce from WebCrypto. WASM module supplied as compiled code, no imports; Worker owns exactly one module instance and Rust session. Worker fatal/trap/transport error terminates; new worker needs new nonce. Client single-flight validates identity, exact tags, generation/revision transitions, page bounds, output size; worker checks output SHA with WebCrypto. No global second Session or full index transfer. Input selected local, transfer copy to Worker, original unchanged. Worker no fetch or network calls; harness only fetches static WASM from loopback. No production integration. Browser test uses actual Chrome Module Worker, file chooser, Blob download and independent oracle outside browser; synthetic public CI only, private original/output never CI or static server. Native and browser same input output exact bytes are regression evidence, not independent semantic acceptance. Genuine local results and independent 06A remain required.
