# HKIA HKS1 — R3 read-only ProductSession contract

Scope: native Rust session and TypeScript caller codec; NOT WASM, Worker deployment, Writer, game authentication or a production adapter. R2 accepted reader reused; R3 adds projections, archive/account and lifecycle. No raw save upload.

- Rust owns one original ZIP/slot/account byte buffer, optional raw slot/account target copies, decoded slot, typed indexes, immutable ZIP member frames and bounded pages. All calls synchronous and exclusive `&mut ProductSession`; future Worker owns one instance, no JS state/writer duplicate. Host creates a nonzero unique cryptographic runtime nonce. The TypeScript gate mirrors only the authoritative stamp and one pending call, never owns the save. A crash/termination invalidates it. Actual WASM/Worker glue pending.
- Stamp: runtime[16], generation u64, revision u64, optional source SHA256[32]. HKS1 binds exact schema SHA256 `a64edcf1da558ab72dab63d9ac27ee9e555812af777581251ab5d4323d2c1a73` and known slot versions 3.0.0/3.0.1. Summary includes schema digest; changing schema/protocol requires new ABI version. Hash is identity, not authentication. All u64/i64 encoded LE exact, TS bigint (not Number).
- Request ID strictly increasing, nonzero, per runtime; foreign runtime rejected without advancing ID; valid same-runtime command consumes ID even on failed CAS/parse; malformed frames not dispatched. Replays/stale revisions/generations/source rejected. Open validates full new source before atomic replacement, increments generation and sets revision 0; failed Open preserves old active source. Close drops state, increments generation, clears source. Read-only revision stays 0. Host gate permits one in-flight call; stale responses cannot commit; Close during outstanding call must wait or terminate and recreate Worker with new nonce. No queued raw bytes in gate.
- Input limits ZIP 60MiB, 2000 members, 25MiB/member, 60MiB total expanded; slot 25MiB/45MiB expanded, 4096 LZ4 blocks, 64KiB/block, 2M logical nodes, 1M container, depth80. Account 2,000,000 UTF8 bytes, depth64, 100k nodes. ZIP32 stored/deflate, local+central exact, signed/unsigned descriptor, full CRC all members; reject path traversal, drive letters, empty components, symlink, ZIP64, multi-disk, unknown flags/method, overlaps and duplicate names. New conservative filename 4096-byte, directory and exact central tail guards. Account rejects ambiguous unpaired surrogate/BOM, duplicate JSON keys (escaped too), case-fold GUID duplicates, invalid values/date; preserves unknown original lexemes, bounded transient tree only. Strictness not generalized to unsupported archives.
- Page limit 128, reply cap 32KiB, offsets u32. Domains 1 slot Achievement, 2 slot Counter, 3 Key1 history, 4 Celebration, 5 Account Achievement, 6 Account Counter, 7 top-level Inventory, 8 Key0 deprecated. Missing/null/zero distinct, history != acquisition. Detail kind 1 CountedValues, 2 CountedGuids, 3 Celebration GUIDs; parent typed document ID; duplicate/order preserved; text detail exposes UTF8 byte length, SHA256, token span (not full text). Raw ranges are offsets in decoded slot or raw Account; never raw bytes. Inventory UniqueData retains raw span and nil/missing state; no inferred acquisition or recipe grant. No full Save JSON or DOM response. Lazy detail scan cost and memory budget remain to benchmark.
- Writer operations Plan/Preview/Apply/Verify/Export/Undo/Redo/Reset all return Unsupported. Internal immutable WriterInput and existing-field CAS witness only: exact stamp, schema, known typed target ID/GUID, old i64 or float bit value, raw token SHA and range. No capability or edit granted. Future Writer requires accepted operation/linkage contract, typed atomic plan, rollback, exact diff, independent reparse and separate export; no future fallback JS writer.

## Binary frame (little endian)
Request: `HKS1` 4, opcode u8, requestId u64, runtime[16], generation u64, revision u64, source-present u8 (0 or 1), digest[32] (all zero if absent), then opcode payload. Header 78 bytes. OPEN=1 + kind u8 (1 ZIP/2 Slot/3 Account) and separately transferred owned bytes. CLOSE=2, SUMMARY=3, PAGE=4 + domain u8/offset u32/limit u16, disabled writer 5..12 no payload, DETAIL=13 + kind u8/parent u32/offset u32/limit u16. No extra bytes, non-Open input rejected.
Reply: `HKS1` 4, requestId u64, stamp (65 bytes), status u8 (0 error + errorCode u8/inputCode u8; 1 success + payloadTag u8). Header through status 78 bytes. Payload 1 opened, 3 summary: kind u8/version u8(0 none,1 v300,2 v301), sourceBytes/archiveEntries/documents/logicalNodes u32, 8 counts u32, deprecated count u32, migration-present u8, if present typed id u32/number i32/span(start/end u32), schemaDigest[32], writerEnabled u8=0. Payload 2 closed: empty. Payload 4 page: domain u8/total u32/offset u32/count u16, rows. Payload 5 detail: kind u8/parent u32/null u8/total u32/offset u32/count u16, rows. Exact row layouts implemented in `src/abi.rs` and `rust-worker/session-abi.ts`; row tag matches page domain. Error codes 1 foreign,2 replay,3 stale,4 no open,5 no domain/identity,6 range,7 unsupported,8 overflow,9 protocol,10 input (subcode per Rust Error). No unrecognized values accepted.
